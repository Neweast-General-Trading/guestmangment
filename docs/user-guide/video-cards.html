Raise a visit

Any staff member, in any department. Set the date, the guests, and any extra need — driver, gift, or gate pass. The line manager must approve first.

Approve the visit

Open Approve, read the guests and the purpose, then approve or return it. Reception cannot prepare until this is done.

Prepare the visit

Reception confirms the visit and the room. Marketing prepares a gift if asked. HR prepares a gate pass if asked. Then Reception sends the party to the guard.
